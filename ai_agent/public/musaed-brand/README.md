# مساعد — حزمة الهوية البصرية

هوية «مساعد»، الوكيل الذكي فوق Frappe / ERPNext. الرمز روبوت صغير ودود: رأس بهوائي وأذنين، وشاشة بترولية تضيء فيها عينان طينيتان.

> للتنفيذ في Frappe عبر Claude Code: افتح `CLAUDE_CODE.md` والصق الأمر الموجود فيه.

---

## الرمز

| العنصر | المعنى | اللون على الطيني |
|---|---|---|
| الهوائي وكرته | متصل دائماً؛ الكرة تنبض حين يستقبل | خط أبيض، كرة بترولية |
| الأذنان | يُصغي قبل أن يجيب | أبيض |
| الرأس | جسم الروبوت | أبيض |
| الشاشة | وجهه؛ عليها كل التعابير | بترولي ‎#0F3D3E |
| العينان | الحضور والانتباه | طيني ‎#D97757 |

**القواعد**
- مساحة الأمان حول الشعار = ٣ × قطر كرة الهوائي.
- أصغر مقاس: الشعار الأفقي بارتفاع 20px، والأيقونة 16px.
- تحت 32px استخدم `icon-small.svg` (تُحذف الأذنان وتكبر العينان).
- فوق الصور استخدم `icon-light.svg`.
- **لا تفعل:** لا تُضِف فماً أو جسداً، لا تغيّر الألوان، لا تمطّ ولا تدوّر الرمز.

## الحركة والحالات

الرأس والهوائي ثابتان دائماً؛ تتغيّر الشاشة وكرة الهوائي فقط.

| الحالة | `data-state` | متى | الحركة |
|---|---|---|---|
| ينتبه | `idle` | الوضع العادي | طفو خفيف + رمشة كل 3.5 ث |
| يرحّب | `welcome` | عند فتح المحادثة | غمزة |
| يستقبل | `listening` | أثناء كتابة المستخدم | نبض كرة الهوائي |
| يعالج | `processing` | بعد إرسال السؤال | ثلاث نقاط تجري على الشاشة |
| يفكّر | `thinking` | أثناء بث الجواب | ينظر للأعلى |
| أنجز | `done` | عند اكتمال الجواب | عينان مبتسمتان بنبضة واحدة |
| خامل | `sleep` | بعد دقيقتين بلا نشاط | عينان مغمضتان، كرة باهتة |

الحركات تتوقف تلقائياً عند تفعيل «تقليل الحركة» في جهاز المستخدم (`prefers-reduced-motion`).
افتح `components/chat-widget-demo.html` في المتصفح لتجربة كل الحالات.
